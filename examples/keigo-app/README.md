# 敬語変換アプリ（学習サイト第7章のサンプル）

くだけた文章を、AI API を使って丁寧なビジネス敬語に書き換えるだけの小さなアプリです。

## 動かし方

1. [Node.js](https://nodejs.org/)（バージョン 20.6 以上）をインストールする
2. OpenAI のサイトで API キーを発行する
3. `.env.example` を `.env` という名前でコピーし、キーを書き込む
4. このフォルダで次を実行する

   ```sh
   node --env-file=.env server.mjs
   ```

5. ブラウザで http://localhost:3000 を開く

## ファイル

| ファイル | 役割 |
| --- | --- |
| `index.html` | 入力欄・ボタン・結果表示（画面） |
| `server.mjs` | プロンプトを組み立て、APIキーを付けて AI に送るサーバー |
| `.env` | APIキー（自分で作る。公開しない） |

モデル名（`gpt-5.4-mini`）は時期によって変わります。動かないときは OpenAI の公式ドキュメントで最新のモデル名を確認してください。
