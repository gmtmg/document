# AIアプリのしくみ教室

「いつものAIチャット」と「APIを使ったAIアプリ」の違いを、初心者が触りながら学べる1ページの学習サイトです。

## 内容

全体を「レストラン」にたとえて説明します（料理人＝AI、注文票＝プロンプト、店員さん＝チャットアプリ、厨房への直通窓口＝API）。
各章の最初に「ひとことで言うと」を置き、コードやJSONなどの細かい話は「もっと詳しく」に折りたたんでいます。

| 章 | テーマ | 触れるところ |
| --- | --- | --- |
| 1 | AIは前の会話を覚えていない | 会話を進めて、AIに渡る注文票が長くなっていく様子を見る |
| 2 | プロンプトって何？ | 「あなたが書いた部分」と「AIに届く全部」を切り替える |
| 3 | なぜ # を使うの？ | ふだん通りの頼み方と、#で整理した指示書を10人分実行して比べる |
| 4 | APIは厨房への直通窓口 | APIに出す注文票の欄を1つずつ光らせて解説 |
| 5 | ボタンを押してから答えが出るまで | 画面 → お店の奥（サーバー） → AI のリレーを1ステップずつ再生 |
| 6 | やってみよう | 指示書の中身をオン・オフして、AIの答えの変化を見る |
| 7 | 自分で作るなら | AIアプリの4つの部品。本物のコードと動かし方は「もっと詳しく」に |
| 8 | 確認クイズ | 5問 |

## 見かた

ビルド不要の静的サイトです。`index.html` をブラウザで開くだけで動きます。
GitHub Pages で公開する場合は、リポジトリの Settings → Pages で、このブランチのルート（`/`）を公開元に指定してください。

## ファイル構成

```
index.html              ページ本体
assets/style.css        デザイン
assets/app.js           動きのあるデモ・クイズ
assets/data.js          実際のAI応答の記録（自動生成）
assets/examples.js      第7章に表示するコード（自動生成）
examples/keigo-app/     第7章の敬語変換アプリ（実際に動くサンプル）
tools/                  上の自動生成ファイルを作るスクリプト
```

## AIの返事について

第3・4・6章に出てくるAIの返事は、作り話ではなく、OpenAI の `gpt-5.4-mini` に実際に送って記録したものです。
記録し直すときは次を実行します（APIの利用料金がかかります）。

```sh
OPENAI_API_KEY=sk-... python3 tools/record_responses.py
```

`examples/keigo-app` のコードを変えたら、サイトの表示も更新します。

```sh
python3 tools/build_examples.py
```
