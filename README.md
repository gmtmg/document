# アプリ作るための基本とか

「アプリを作ってみたい」人のための、何も知らないところから始める学習サイトのシリーズです。
どのページも「そもそもの前提」から始まり、触って試せるデモで説明します。
どのページでも、右下にいるAIの **チャシー** に、わからないところを質問できます。チャシーは、いま読んでいるページと章に合わせて、図や表も使ってやさしく答えます。

## ページ

| ページ | ファイル | 内容 |
| --- | --- | --- |
| トップ | `index.html` | そもそもの前提（アプリ・コード・画面と裏方・通信・ファイル）、レッスン一覧、用語ミニ辞典 |
| AIアプリのしくみ | `ai-app.html` | ChatGPTとAIの違い、プロンプト、#の書き方、API、アプリ工房、敬語変換アプリ |
| GitHubってなに？ | `github.html` | セーブ（コミット）体験、GitとGitHubの違い、プッシュ・プル、ブランチとプルリクエスト |
| オンライン通信に対応しているアプリ | `online.html` | 機内モード体験、リクエストとレスポンス、データの置き場所、リアルタイム通信 |

## チャシー（AIチャットボット）を使うには

いまは **キー入力方式** です。サーバーは要りません。

1. OpenAI の管理画面で、チャシー用の APIキーを作る（**月の利用上限を低めに設定**しておく）
2. そのキーを、使ってほしい人にだけ、LINE の個別メッセージなどで渡す
3. 受け取った人がサイトを開き、右下のチャシーを押して、「APIキーを入れてね」の欄に貼り付ける

キーはその人のブラウザの中にだけ保存され、ブラウザから直接 OpenAI に送られます。GitHub やサイトのファイルには、キーは一切入りません。
使い終わったら、OpenAI の管理画面でそのキーを削除すれば止められます。

**キーを GitHub（Secrets や環境変数、ファイル）に置いてページから使うことはしないでください。** GitHub Pages のページは誰でも中身を見られるので、キーが全世界に公開されてしまいます。

たくさんの人に公開したくなったら、キーを隠しておけるサーバーを使う **サーバー方式** に切り替えられます。手順は [`worker/README.md`](worker/README.md) にあります。

## AIアプリのしくみ（ai-app.html）の章立て

全体を「レストラン」にたとえて説明します（料理人＝AI、注文票＝プロンプト、店員さん＝チャットアプリ、厨房への直通窓口＝API）。
各章の最初に「ひとことで言うと」を置き、コードやJSONなどの細かい話は「もっと詳しく」に折りたたんでいます。

| 章 | テーマ | 触れるところ |
| --- | --- | --- |
| 0 | そもそも：AIとAIアプリってなに？ | 書き出しの続きを見る、AI本体を自分のアプリで借りる |
| 1 | AIは前の会話を覚えていない | 会話を進めて、AIに渡る注文票が長くなっていく様子を見る |
| 2 | プロンプトって何？ | 「あなたが書いた部分」と「AIに届く全部」を切り替える |
| 3 | なぜ # を使うの？ | ふだん通りの頼み方と、#で整理した指示書を10人分実行して比べる |
| 4 | APIは厨房への直通窓口 | APIに出す注文票の欄を1つずつ光らせて解説 |
| 5 | ボタンを押してから答えが出るまで | 画面 → お店の奥（サーバー） → AI のリレーを1ステップずつ再生 |
| 6 | やってみよう | 指示書の中身をオン・オフして、AIの答えの変化を見る |
| 7 | 自分で作るなら | AIアプリの4つの部品。本物のコードと動かし方は「もっと詳しく」に |
| 8 | 確認クイズ | 5問 |

## 見かた

ビルド不要の静的サイトです。`index.html` をブラウザで開くだけで動きます。
GitHub Pages で公開する場合は、リポジトリの Settings → Pages で、このブランチのルート（`/`）を公開元に指定してください。

## ファイル構成

```
index.html              トップページ
ai-app.html             AIアプリのしくみ
github.html             GitHubってなに？
online.html             オンライン通信に対応しているアプリ
assets/style.css        全ページ共通のデザイン
assets/common.js        全ページ共通の動き（進捗バー・章ナビ・クイズ）
assets/hub.js           トップページの動き
assets/ai.js            AIアプリのページの動き
assets/github.js        GitHubのページの動き
assets/online.js        通信のページの動き
chat.html               （以前のチャシーのページ。トップページへ移動するだけ）
assets/chacy.js         チャシー（どのページでも右下に出る質問パネル）
assets/chat-config.js   チャシーの設定（キー入力方式 / サーバー方式）
assets/vendor/          Markdown・図を表示するライブラリ（marked / DOMPurify / Mermaid）
worker/                 チャシーの指示書（src/system-prompt.js）と各ページの要約（src/pages.js）、サーバー方式用のサーバー
.github/workflows/      チャシーのサーバーを自動で公開する設定
assets/data.js          実際のAI応答の記録（自動生成）
assets/examples.js      AIページ第7章に表示するコード（自動生成）
examples/keigo-app/     第7章の敬語変換アプリ（実際に動くサンプル）
tools/                  上の自動生成ファイルを作るスクリプト
```

## AIの返事について

AIアプリのページの第3・4・6章に出てくるAIの返事は、作り話ではなく、OpenAI の `gpt-5.4-mini` に実際に送って記録したものです。
記録し直すときは次を実行します（APIの利用料金がかかります）。

```sh
OPENAI_API_KEY=sk-... python3 tools/record_responses.py
```

`examples/keigo-app` のコードを変えたら、サイトの表示も更新します。

```sh
python3 tools/build_examples.py
```
