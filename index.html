そもそもの前提

知っている人には当たり前すぎて、誰も説明してくれないこと。この5つだけ押さえれば、どのレッスンも読めます。

前提 1

アプリは「手順書」で動いている

アプリ（アプリケーション）は、コンピューターに「こうなったら、こうして」という手順を書いたものです。コンピューターは賢そうに見えますが、実は書かれた手順どおりにしか動けません。

たとえば、すごく簡単な「おみくじアプリ」の手順書はこうなります。ボタンを押して、手順書のどこが動いているか見てください。

おみくじアプリの手順書
  1. ボタンが押されるのを待つ
  2. 「大吉・中吉・小吉・凶」の中から、1つをでたらめに選ぶ
  3. 選んだものを画面に出す
おみくじアプリ
？

覚えておくことアプリ ＝ コンピューターへの手順書。手順に書いていないことは、何もできない。

前提 2

「プログラム」「コード」は、手順書のこと

手順書は、日本語ではなくコンピューター用の書き方（プログラミング言語）で書きます。この手順書を「プログラム」や「コード」と呼びます。むずかしそうに見えますが、中身はただの文字です。メモ帳でも開けます。

さっきのおみくじを、本物のコード（JavaScriptという言葉）で書くとこうなります。行ごとに、同じことを言っています。

① ボタンが押されたら、次のことをする：

② 「大吉・中吉・小吉・凶」を用意する
   その中から1つをでたらめに選ぶ

③ 選んだものを画面に出す
// ①
button.onclick = () => {
  // ②
  const list = ["大吉", "中吉", "小吉", "凶"];
  const pick = list[Math.floor(Math.random() * 4)];
  // ③
  result.textContent = pick;
};

覚えておくことプログラム ＝ コード ＝ 手順書。特別な書き方をしているだけで、ただの文字。

前提 3

アプリは「見える部分」と「裏方」に分かれている

おみくじのような簡単なアプリは、スマホの中だけで完結します。でも、ネットショップやLINEのようなアプリは、2つの部分に分かれています。

画面 あなたのスマホやパソコンに表示される、見える部分。
裏方（サーバー） インターネットの向こうにある、別のコンピューター。データをしまったり、計算したりする。

レストランでいえば、画面は客席、サーバーは厨房です。下のネットショップの部品を押してみてください。

覚えておくこと画面（客席）は見せる係。サーバー（厨房）は、データをしまって計算する係。

前提 4

インターネットは、コンピューター同士の「手紙のやり取り」

画面とサーバーは、遠く離れた別々のコンピューターです。この2つは、インターネットを通じて「〇〇をください」「はい、どうぞ」という手紙を一瞬でやり取りしています。

あなたがスマホで天気を見るときも、スマホが天気の会社のサーバーに「東京の天気をください」と手紙を出して、返事を表示しているだけです。

くわしくは レッスン「オンライン通信に対応しているアプリ」 で、実際に手紙を飛ばしながら説明します。

覚えておくこと通信 ＝ 「ください」と「どうぞ」の手紙のやり取り。

前提 5

アプリは、たくさんの「ファイル」の集まり

写真や文書と同じように、アプリもファイルでできています。ファイルはフォルダに整理されています。たとえば、いま見ているこのサイトは、こんなファイルの集まりです。

document/                ← このサイトのフォルダ
├─ index.html          ← このページ
├─ ai-app.html         ← AIアプリのレッスン
├─ github.html         ← GitHubのレッスン
├─ online.html         ← 通信のレッスン
├─ assets/             ← 見た目や動きのファイル
│  ├─ style.css
│  └─ hub.js …
└─ examples/           ← サンプルのアプリ

アプリを作るとは、このファイルを書いて、何度も書き直していく作業です。

何度も書き直していると「前の方が良かった」「どこを変えたっけ？」と困ります。それを助けてくれるのが レッスン「GitHubってなに？」 で説明するGitとGitHubです。

覚えておくことアプリ ＝ ファイルの集まり。作る ＝ ファイルを書いて、書き直すこと。
